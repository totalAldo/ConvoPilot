# ConvoPilot Public Docs

Public support and privacy information for ConvoPilot, a privacy-first conversation support app for iPhone.

- [ConvoPilot website](https://totalaldo.github.io/ConvoPilot/)
- [Support](https://totalaldo.github.io/ConvoPilot/support/)

## Files

- `index.html`: landing page with links to support and privacy.

- `privacy/index.html`: public privacy policy page.
- `styles.css`: shared styles for the static pages.
